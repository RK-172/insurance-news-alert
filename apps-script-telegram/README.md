# 보험정책 알림을 Google에서 받기

기존 Google 시험 프로젝트와 텔레그램 봇 **@News_alert_test172_bot**을 사용합니다. 시험 메시지를 휴대폰으로 확인한 뒤 발송을 넘길 수 있습니다. 기존 기록표와 오전 6시부터 오후 9시 전까지의 5분 타이머를 계속 사용합니다.

1. [Google Apps Script 내 프로젝트](https://script.google.com/home)에서 지난번 **보험정책 모니터 시험** 프로젝트를 엽니다. 이름을 바꿨다면 편집기의 기존 코드에 `setupTrial`과 `runScheduledProbe`가 들어 있는지 확인합니다.
2. [Code.gs](./Code.gs)를 열고 파일 오른쪽 위 **Copy raw file**을 누릅니다. Apps Script의 `Code.gs` 코드 영역을 클릭하고 **Ctrl+A → Ctrl+V → Ctrl+S**를 누릅니다.
3. 텔레그램 [공식 BotFather](https://t.me/BotFather)와 나눈 기존 대화에서 해당 봇의 토큰을 복사합니다. 찾기 어려우면 BotFather에 `/mybots`를 보내 기존 봇의 **API Token**을 엽니다. 지금 사용하는 토큰을 그대로 쓰면 GitHub도 계속 알림을 보낼 수 있습니다.
4. Apps Script 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 수정 → 스크립트 속성 추가**에서 이름 `TELEGRAM_BOT_TOKEN`과 복사한 토큰을 입력하고 저장합니다. 기존 속성은 보존합니다. 개인 채팅 ID를 알고 있다면 `TELEGRAM_CHAT_ID`도 추가할 수 있습니다. 비밀값은 본인 프로젝트의 속성에만 입력합니다.
5. **〈〉 편집기**로 돌아가 위쪽 함수 목록에서 `testTelegram`을 골라 **실행**합니다. 채팅 ID를 따로 입력하지 않았다면 하단 **실행 로그**의 본인 전용 링크를 열고 텔레그램에서 **시작(Start)**을 누릅니다. 또는 로그에 표시된 `/start …` 한 줄 전체를 해당 봇과의 개인 대화에 보냅니다. 이어서 `testTelegram`을 한 번 더 실행합니다. 링크는 20분 동안 유효합니다. 휴대폰에서 **[보험정책 모니터 / 연결 시험]**을 확인합니다.
6. 같은 함수 목록에서 `prepareTelegramSwitch`를 골라 **실행**합니다. 로그에 **전환 준비 완료**가 나오면 [GitHub의 Insurance news monitor](https://github.com/RK-172/insurance-news-alert/actions/workflows/monitor.yml)를 열고 오른쪽 위 **⋯ → Disable workflow**를 누릅니다. 오류가 뜨면 GitHub가 계속 발송하도록 두고, 오류 문구만 확인합니다.
7. 마지막 GitHub 작업이 끝나면 Google이 다음 주간 점검에서 전환합니다. 기존 기록표의 **요약 → 상태**가 **Google 텔레그램 발송 중**이면 완료입니다. 밤 9시 이후라면 다음 날 오전 6시 이후 첫 점검에서 확인할 수 있습니다. 새 글의 처리 결과는 **텔레그램 발송** 탭에 기록됩니다.

## 어떤 알림을 받나요?

금융위원회와 금융감독원의 7개 게시판을 확인합니다. 목록에서 관련 키워드를 찾지 못하면 상세 본문을 확인하고, 본문을 읽기 어려운 자료는 누락을 줄이기 위해 발송합니다. 기관·분류, 제목, 원문 주소를 세 줄로 보내며 첨부파일은 다운로드하지 않습니다. 국회 의안 수집은 별도 연결 대상입니다.

Google은 전환할 때 마지막 GitHub 처리 기록과 시험 기록표를 대조합니다. 전환 중에 발견한 글과 GitHub의 미발송 자료를 이어받습니다. 정상 운영 중에는 Google이 게시판을 직접 조회합니다. 발송에 실패한 자료는 대기열에서 다음 주간 점검에 재시도합니다. 통신이 끊겨 텔레그램이 이미 수신한 응답을 확인할 수 없는 경우에는 드물게 중복될 수 있습니다. 점검 공백이 길어지면 게시판별 최근 3쪽까지 확인하며 이전 기록에 닿지 못하면 기록표에 표시합니다.

기록표의 상태가 **전환 대기**로 계속 표시된다면 주간 점검 시각과 오류 문구를 확인하세요. **Google 텔레그램 발송 중**인 동안에는 GitHub 정기 발송을 다시 켜면 두 발송처에서 같은 자료가 올 수 있습니다.
